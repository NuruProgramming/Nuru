# Nuru Snippets Pack

A comprehensive collection of fast, clean code snippets for the **Nuru** programming language in Visual Studio Code.

## Features

Quickly insert common Nuru syntax structures using intuitive prefixes (in both Swahili keywords and English aliases):

| Prefix | Description |
| :--- | :--- |
| `fanya` / `var` | Variable declaration |
| `andika` / `print` | Console output |
| `jaza` / `input` | Console user input |
| `unda` / `fn` | Function definition |
| `undacallback` / `cb` | Anonymous function / callback |
| `kama` / `if` | `kama` conditional statement |
| `kamasivyo` / `ifelse` | `kama ... sivyo` block |
| `aukama` / `elseif` | `kama ... au kama ... sivyo` block |
| `wakati` / `while` | `wakati` loop |
| `kwakila` / `for` | `kwa ... katika` loop |
| `badili` / `switch` | `badili` switch block |
| `orodha` / `list` | List / Array initialization |
| `kamusi` / `dict` | Dictionary initialization |
| `acha` / `break` | Break out of a loop |
| `nurustarter` / `main` | Starter Nuru script template |

## Requirements

Works best alongside the [Nuru Language Support](https://open-vsx.org/extension/nidalbenyakhelf/nuru-lang) extension for syntax highlighting.
